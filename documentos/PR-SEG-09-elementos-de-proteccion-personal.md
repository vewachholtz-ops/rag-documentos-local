# PR-SEG-09 Elementos de protección personal

Versión 2, vigente desde el 1 de marzo de 2026. Responsable: gerente de seguridad.

## EPP básico

En toda la faena, fuera de oficinas y comedores, se usa casco, lentes de seguridad, zapatos de seguridad y chaleco reflectante, y protección auditiva donde el ruido supera 85 dB.

## Color del casco

| Color | Quién lo usa |
|---|---|
| Blanco | Supervisores y jefaturas |
| Amarillo | Operadores y mantenedores |
| Verde | Personal de seguridad y salud |
| Azul | Visitas |
| Naranja | Trabajadores contratistas |

## Reposición

El EPP dañado se cambia sin costo en la bodega de EPP, entregando el elemento dañado. El casco se cambia cada 3 años aunque no tenga daños.

## Fiscalización

El supervisor revisa el EPP al inicio del turno. Un trabajador sin el EPP básico no puede entrar al área de trabajo.
