# Documentos de ejemplo

Procedimientos **ficticios** de "Faena Cerro Alto", una mina inventada. Se escribieron para probar el RAG: no corresponden a ninguna empresa real y no deben usarse como procedimientos de trabajo.

Son 24 archivos de 9 áreas (abastecimiento, bodega, inventario, mantención, seguridad, medio ambiente, personas, finanzas y proyectos). Varios se parecen a propósito: dos tablas de aprobaciones (compras y contratos de servicios), dos pautas de mantención (camiones y palas), dos cursos con distinta vigencia y dos horarios de bodega. `PR-COM-01-v4-solicitud-de-compra.md` es la versión **obsoleta** de un procedimiento vigente, con montos distintos: el índice la descarta por su línea `Estado: obsoleto`.
